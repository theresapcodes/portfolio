What a usage page looks like

Every component gets one page in the same order, so designers and engineers know where to look. This is the Button page.

Purpose
Starts an action. Use a link for navigation, a button for actions that change something.
Variants
  • Primary: the one main action on a screen. Use once per view.
  • Secondary: supporting actions next to a primary.
  • Ghost: low-emphasis actions in toolbars and tables.
  • Danger: destructive actions, always behind a confirmation.
States
Default, hover, focus, active, disabled. Loading replaces the label with a spinner and keeps the width.
Accessibility
  • Minimum target size of 40 by 40 pixels at the medium size.
  • Visible focus ring using --color-border-focus.
  • Label text must describe the action. Icon-only buttons need an aria-label.
  • Text contrast of at least 4.5:1 in light and dark themes.
Code
<Button variant="primary" size="md">Save changes</Button>

What engineering receives

A folder of files that live in your repo: tokens, a component inventory, usage pages, and a rules file for AI coding tools. The JSON tokens are the source of truth.

tokens/tokens.json

{
  "color": {
    "semantic": {
      "action": {
        "primary": {
          "bg": { "$value": "{color.primitive.brand.600}" },
          "text": { "$value": "#FFFFFF" }
        }
      }
    }
  }
}

tokens/tokens.css

:root {
  --color-action-primary-bg: #4F46E5;
  --color-action-primary-text: #FFFFFF;
  --radius-md: 8px;
  --space-4: 16px;
}
[data-theme="dark"] {
  --color-action-primary-bg: #6366F1;
}

shadcn/ui theme mapping

:root {
  --primary: var(--color-action-primary-bg);
  --primary-foreground: var(--color-action-primary-text);
  --border: var(--color-border-default);
  --ring: var(--color-border-focus);
  --radius: var(--radius-md);
}

AGENTS.md (excerpt)

1. Never hardcode a color, size,
   radius, or shadow. Use a token.
2. Use semantic tokens only.
3. Use an existing component from
   components.json before building
   a new one.
4. Every interactive element needs
   all its states.
